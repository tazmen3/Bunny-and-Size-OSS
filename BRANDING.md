## Provenance et adaptations

Image personnelle fournie par Louis Lejuez le 24 octobre 2026. Le maître est une
adaptation assistée par l'outil intégré OpenAI ImageGen : extraction/recomposition
du lapin blanc/gris à cape rouge, sans portrait ni décor. Le prompt et les hashes
sont conservés dans PROVENANCE.json. Aucune garantie d'exclusivité de l'outil
n'est déduite. Aucune image récupérée sur un service externe n'est utilisée.

Maître PNG 1254 × 1254 avec alpha ; PNG 16/24/32/48/64/128/256/512 ; ICO
16/24/32/48/64/256. Le maître est la source préférée de modification du lapin
adapté, sans besoin de l'original privé. Le script `scripts/build_branding.py`
convertit les tailles avec Pillow 10.2.0 ; la bannière SVG compose l'icône adaptée
sans portrait. Aucun appel réseau au démarrage. Les onze fichiers graphiques
couverts sont identifiés individuellement dans PROVENANCE.json.
