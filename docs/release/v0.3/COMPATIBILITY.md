# Compatibilité du candidat v0.3

Cibles desktop : Ubuntu 24.04 x86_64, X11/XWayland et Windows 11 x64 MSVC.
Windows nécessite le runtime Microsoft Visual C++ Redistributable x64 v14.
Les dépendances système Linux et les limites de saisie figurent dans README.md.
La validation native exécutée pour chaque révision est décrite dans la PR privée.
Android demeure expérimental ; aucun scan SAF ni appareil réel certifié.
