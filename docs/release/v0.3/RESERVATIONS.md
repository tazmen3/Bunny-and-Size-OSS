# Réserves du candidat v0.3

Candidate interne 0.3.0-rc.1 du 26 octobre 2026 ; aucune publication publique autorisée. Aucun résultat de CI désactivée
n'est déduit des tests locaux. Les tests automatisés ne sont pas une recette humaine.
Wayland natif, accessibilité exhaustive et Windows physique non certifiés.
L'exploration complémentaire #93 garde un coût O(N) par demande hors cache,
donc O(P×N) pour P pages. Les performances VM ne décrivent pas un PC physique.
La publication exige les sources correspondantes et leurs notices, un examen du
manifeste public et une autorisation de release séparée.
