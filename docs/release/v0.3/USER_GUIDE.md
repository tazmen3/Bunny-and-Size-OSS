# Bunny and Size v0.3 — candidate interne 0.3.0-rc.1

SortSize devient Bunny and Size. Lancer `bunny-and-size` sous Linux ou
`bunny-and-size.exe` sous Windows. La CLI distincte `bunny-and-size-cli` fournit
les mêmes options que la commande historique `sortsize`, conservée.
Voir docs/CLI.md, docs/ENTRIES_EXPORT.md et docs/GUI.md dans cette archive.

Les préférences existantes sont reprises depuis le même dossier `sortsize` du
profil utilisateur ; aucun déplacement au démarrage. Voir MIGRATION_V03.md.
Analyse locale en lecture seule, cinq langues, progression #92 et exploration
complémentaire bornée #93. Aucune opération destructive ni télémétrie.
