# SortSize 0.2.0-rc.1

SortSize propose une analyse locale du stockage en lecture seule, avec une interface graphique et une CLI. Cette première candidate v0.2 pour Ubuntu et Windows ajoute notamment Treemap, Top 100, métadonnées et exports détaillés. Elle est destinée aux essais et conserve les limitations décrites ci-dessous.

Candidate desktop Ubuntu 24.04 x86_64 / Windows 11 x64. Interface actuellement en français. Les archives publiques préparées conservent les exécutables qualifiés et le code produit 448e92e ; seuls des documents historiques et métadonnées de conteneur sont expurgés/actualisés. Aucune publication réalisée. Consulter RELEASE_NOTES.md, USER_GUIDE.md, KNOWN_ISSUES.md et les sources correspondantes avant diffusion.
