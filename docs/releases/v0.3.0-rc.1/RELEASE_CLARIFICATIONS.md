The owner authorized the first public **V0.3.0-rc.1 on 26 October 2026**, accepting unfixed D1 and the documented reservations. For this RC only, this supersedes the earlier internal-V0.3 / first-public-V0.4 plan. V0.4 remains the next functional development stage.

These dated texts do not describe the current public decision; these clarifications and the external release notes and limitations supplement them. Embedded “not validated” statements remain historical and do not negate later native campaigns. Historical source documents may retain internal references as text; private evidence is not distributed.

All four archives, manifests, corresponding sources and SHA-256 hashes remain unchanged. No repackaging or recompilation. The product is frozen at `addf68704f26ef02559dd56b2e9b75b168fd0752`. New tests and reports remain separate in the private repository. The OSS repository contains only the public selection from this frozen source plus current public documentation, within its own Git history.

**D1 remains unfixed.** Failure to reproduce it does not demonstrate a fix. Future product changes require a new candidate, new archives, hashes and native qualification. RC.1 files must not be silently replaced.
