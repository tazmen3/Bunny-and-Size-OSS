# Sécurité

Téléchargez depuis les [releases du projet](https://github.com/tazmen3/Bunny-and-Size-OSS/releases).
Vérifiez les empreintes SHA-256 fournies. Les exécutables Windows 0.5.0-rc.2 sont
distribués sans signature Authenticode. [Distribution Windows](CODE_SIGNING.md)

Pour un signalement de sécurité, utilisez le signalement privé du dépôt
lorsqu’il est disponible. Évitez de joindre des données sensibles à une issue publique.
