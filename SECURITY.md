# Sécurité — Bunny and Size v0.4.0-rc.1

Version d’évaluation avec réserves, sans engagement de compatibilité universelle.
Les exécutables Windows sont non signés, l’éditeur non vérifié ; SmartScreen peut avertir ou bloquer,
et les politiques de postes administrés peuvent interdire le lancement. SignPath Foundation a refusé la candidature ;
aucune signature ou approbation SignPath n’est revendiquée.

Télécharger depuis la [release officielle](https://github.com/tazmen3/Bunny-and-Size-OSS/releases/tag/v0.4.0-rc.1), vérifier les sept noms, tailles et SHA-256 publiés,
puis extraire l’intégralité de l’archive. Un SHA-256 vérifie l’intégrité, pas l’identité de l’éditeur.
Conserver Defender, SmartScreen et les politiques de sécurité actifs. Ne pas contourner un blocage inattendu.
Le parcours physique Mark of the Web / SmartScreen est **NOT_RUN**.

D1 #139 demeure UNRESOLVED ; #89 demeure ouverte. Les réserves d’accessibilité humaine,
DPI/multi-écrans et SMB physique figurent dans les notes de release.
L’analyse est en lecture seule par défaut et les fonctions locales ne transmettent pas de télémétrie.
Pour signaler une vulnérabilité sans publier de données sensibles, utiliser l’onglet Security / Report a vulnerability
du dépôt lorsqu’il est disponible ; ne pas joindre de secrets à une issue publique.
